# FULL CONTACT FORMS - GREENYURI RECORDS
Misión M4 · Full Contact Form Valida o MUERE — Web Development I. 

## Cómo probarlo
La app simula la gestión de una tienda de discos, con una base de datos propia en JSON donde se almacenan los distintos discos a la venta, con sus diferentes características (estilos, autores, formatos...). Mediante el formulario modo GRUD se permite añadir, eliminar, modificar y mostrar discos. Utilidades CRUD. Limpieza con Zod y safeParse.
